# Futsal Management System

A web-based **Futsal Management System** developed during an internship program using **Java J2EE** and **JSF**.  
The system helps manage futsal bookings, schedules, users, and administrative operations through a responsive web interface.

---

## Technologies Used

- Java J2EE
- JSF (JavaServer Faces)
- HTML
- CSS
- JavaScript
- Bootstrap
- MySQL

---

## Features

- User Registration & Login
- Futsal Booking Management
- Schedule Management
- Admin Dashboard
- Responsive UI Design
- Database Integration with MySQL
- Dynamic Web Pages using JSF

---

## Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/futsal-project.git
```

### 2️⃣ Import the Project

Import the project into:

- Eclipse IDE
- NetBeans
- IntelliJ IDEA

Configure the project with **Apache Tomcat Server**.

---

### 3️⃣ Configure Database

- Create a MySQL database
- Import the SQL file
- Update database credentials in the configuration file

---

### 4️⃣ Run the Application

Start the Tomcat server and open:

```bash
http://localhost:8080/Futsal-Project
```
